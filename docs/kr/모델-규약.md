## 새 연구 코드의 좌표와 단위

| 대상 | 규약 |
|---|---|
| world | NED: x 북쪽, y 동쪽, z 아래쪽. 실제 사용 시 기준 방향/원점을 정해야 함 |
| body | FRD: x 전방, y 오른쪽, z 아래쪽. 축은 질량중심에서 정의 |
| 자세 | `R_ned_from_frd`: body 벡터를 world 벡터로 바꾸는 회전행렬 |
| 위치/속도/각도/각속도 | m / m/s / rad / rad/s |
| 힘/토크/관성 | N / N·m / kg·m² |
| 높이 | 사용자 표시 높이 `h=-z_down`. 위로 올라가면 높이는 증가, z_down은 감소 |
| TVC alpha, beta | 실제 짐벌 각도. 서보축 각도, PWM %, 기어비 보정값과 다름 |
| 회전 순서 | `d = Rx(alpha) Ry(beta) [0,0,-1]`. 곱의 순서를 바꾸면 일반적으로 다른 모델 |

ROS의 ENU/FLU 인터페이스로 변환할 때는 world와 body를 모두 변환한다.
`v_ENU=[v_E,v_N,-v_D]`, `v_FLU=[v_F,-v_R,-v_D]`이며,
회전행렬은 `R_ENU_from_FLU = C_world R_NED_from_FRD C_bodyᵀ`다.
이 규약은 [ROS REP-103 원문](https://raw.githubusercontent.com/ros-infrastructure/rep/master/rep-0103.rst)의
SI/오른손 좌표계/ENU/FLU 관례와 맞추기 위한 경계 변환이다.
카메라 optical frame은 별도이며 설치 자세와 외부 보정이 추가로 필요하다.

**원본 센서 축이 실제 FRD로 장착되어 있다는 뜻은 아니다.** 원본에는 Fusion NED 설정과 함께
위로 양수인 높이, 초기 yaw 오프셋 등이 있다. 실제 기체 축/센서 장착/로컬 좌표계를 확인하기 전에는
원본 텔레메트리를 이 함수에 바로 넣지 않는다. 위 변환은 규약이 확인된 입력에만 적용한다.

## 힘·토크 모델

공통 TVC 유효 작용점이 질량중심 아래 `r=[0,0,l]`에 있고 두 로터가 같은 추력축을 공유한다는 초기 모델이다.

```text
d = [-sin(beta), sin(alpha)cos(beta), -cos(alpha)cos(beta)]
F_body = T_total * d
tau_body = r × F_body - Q_reaction * d
a_world = R * F_body / mass + [0,0,g]
omega_dot = inverse(J) * (tau_body - omega × (J * omega))
```

양의 `Q_reaction`은 짐벌 중립에서 body +z 토크를 뜻한다.
이는 가상 힘·토크 입력 규약이며, 현재 모터의 회전 방향이나 토크 계수가 확인된 것은 아니다.
위 식의 기반은 [질량중심 기준 Newton–Euler 동역학](https://vnav.mit.edu/material/06-Control1-notes.pdf)이다.
자유비행 중력은 병진 가속도에 들어가고 질량중심 기준 전복 토크를 별도로 추가하지 않는다.
고정축 지그나 줄의 힘, 프로펠러/짐벌 관성, 로터 자이로 효과, 동축 간섭, 항력과 지면 효과는 아직 포함하지 않는다.

단순 모터 추력 분해는 `T1=(T_total+D)/2`, `T2=(T_total-D)/2`다.
`D=T1-T2`이며, 두 로터가 역추력을 만들지 않는다면 `|D|<=T_total`이어야 한다.
이 함수는 합/차 보존 확인용이고 전압별 PWM 보정이나 최대 추력 제약을 대신하지 않는다.

## 파라미터 한 곳에서 관리하기

2026-09-16: 프로파일 분리·검사·실행 방법은 [3단계 B — 파라미터 관리](파라미터-관리.md)에 정리했다.
원본 참고 파일은 보존하고, 내 기체 입력은 `research/parameters/my_airframe.json`에서 별도로 관리한다.
내 기체의 미정값을 원본 값으로 자동 대체하지 않는다.

파일: `research/parameters/upstream_reference.json`.
각 항목에 값, 단위, 출처, 상태(`upstream_reference`/`convention`/`assumed`/`unknown`)를 기록했다.
현재 본인 기체의 실측값은 없다. 원본 수치를 나중에 본인 기체의 실측 프로파일과 구분해 보존한다.

- 원본 기준: 질량 0.430 kg, 레버암 0.205 m, Ixx/Iyy 0.01802468421 kg·m².
- 초기 가정: 서보 시정수 40 ms, 짐벌 출력 각속도 한계 180°/s. MG90S의 검증된 사양이 아니다.
- 미정: Izz, 차동추력→로터 반작용 토크 계수, 배터리 하한에서의 최대 총추력.
- 미정 값은 `null`이다. 0으로 바꾸거나 Ixx를 Izz에 복사하지 않는다.
- 대각 관성행렬을 요청하면 Izz가 미정인 동안 오류를 내게 했다. 이는 의도된 제한이다.

기존 1축 서보 실험도 공통 파일에서 질량·관성·레버암·구동기 가정을 읽도록 연결했다.
상태/입력 비용과 실험 외란 등의 실험 설계는 별도로 남아 있다.

## 원본 LQI와 SI 버전의 비교

새 축약 호버 모델의 상태는
`[phi,theta,psi,z_down,p,q,r,v_down,int_phi,int_theta,int_psi,int_z_down]`,
입력은 `[alpha_rad,beta_rad,D_N,delta_T_N]`다.
횡방향 위치·속도는 이 12상태 모델에 없으며, 큰 기울기의 회전이나 구동기 지연을 포함한 완전한 비선형 시뮬레이터도 아니다.

원본 수식을 비교하기 위한 **대수적 대응**은 다음과 같다.

- 높이, 수직 속도, 높이 적분의 부호를 바꾼다.
- `alpha=u0`, `beta=-u1`, `D_N=g*u2`, `delta_T_N=u3`로 입력을 바꾼다.
- `x_SI=S*x_old`, `u_SI=U*u_old`이면 `A_SI=S*A_old*S⁻¹`, `B_SI=S*B_old*U⁻¹`.
- 비용도 `R_SI=U⁻ᵀ*R_old*U⁻¹`로 변환한다. 특히 yaw 입력 비용은 기존 값에서 `g²`로 나뉜다.
- 동일한 수학적 제어라면 `K_SI=U*K_old*S⁻¹`가 된다.

여기서 원본 u2는 kg로 표시된 **질량 환산 추력**이라는 임시 해석이다.
코드에 사용된 `g=9.81`로 대응한 것이며, 엄밀한 표준 kgf 변환(9.80665)을 새로 도입한 것이 아니다.
센서 좌표나 실제 모터 추력 보정을 완료한 것으로 해석하면 안 된다.

특히 원본 `freertos.c`는 두 모터 보정 함수에 각각 `thrust/G ± u2/2`를 넣는다.
새로운 물리 모터 분해식과 달리 공통항에 1/2이 없지만, 보정 데이터가 단일 모터인지 동축 조립체인지
확인되지 않았다. 따라서 곧바로 "추력이 두 배인 버그"라고 단정하거나 펌웨어에 1/2을 추가하지 않았다.
원본 서보 명령에는 별도의 `NOMINAL_THRUST/clamped_thrust` 배율도 있어 실제 입력 전달 특성은 추가 검증 대상이다.
이번 단계에서 보장하는 것은 Python 선형 계산의 좌표/단위 등가성뿐이다.
