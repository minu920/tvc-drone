# 5단계 — 연구기체 기준 사양 v1과 전체 과정

작성: 2026-09-16. 개정: 2026-09-20 (v0 → v1).
이 사양은 보유 장비를 판정하고 첫 벤치를 만들기 위한 시작점이다.
특정 모터·프로펠러 조합의 비행 성능을 보증하지 않으며, 계측 결과에 따라 변경한다.

## v1에서 바뀐 것

추진계 선택이 확정되면서 v0의 전원·프로펠러·질량 기준이 모두 바뀌었다.
v0 §11의 개정 조건 중 "실측 총추력 미달"과 "질량 변경"에 해당하므로 정상적인 설계 반복이다.

| 항목 | v0 | v1 | 근거 |
|---|---|---|---|
| 전원 | 6S LiPo | **4S LiPo** | 보유 구성 확정 |
| 프로펠러 | 8–9인치 | **APC 12×4.5MR / 12×4.5MRP** | 아래 참조 |
| 질량 상한 | 1.8 kg | **1.5 kg** | 2026-09-20 결정 |
| 추력/무게 목표 | 2.0 | **1.7** | 2026-09-20 결정, 감수 사항은 §1에 기록 |
| 총추력 목표 | 37 N | **25.9 N** | 새 질량·목표로 재계산 |
| 모터 | 2808–3110급 / 700–1000 KV | **D4215-21 650KV × 2** | 보유 구성 확정 |
| ESC | 60–80 A | **50–60 A × 2** | 새 전류 범위 |

**프로펠러가 12×3.8SF에서 12×4.5MR로 바뀐 이유.**
APC는 계열별 RPM 상한을 `상수 ÷ 직경(inch)`으로 공표한다. Slow Flyer 계열의 상수는 65,000이므로
12인치 SF의 상한은 5,417 RPM이다. 그런데 이 구성에서 목표한 모터당 1.62 kgf를 12×3.8SF로 내려면
약 7,272 RPM이 필요하다. 상한의 134%이며, 12인치 블레이드에서 허용할 수 없는 조건이다.
상한을 지켜 5,417 RPM으로 제한하면 동축 총추력이 1.43 kgf로 떨어져 1.5 kg 기체가 뜨지 않는다.
Multi-Rotor 계열은 상수가 105,000이라 12인치 상한이 8,750 RPM이고, 같은 추력을 상한의 88%에서 낸다.
직경이 같으므로 기구 설계 영향은 없다. 정·역회전 짝은 `MR`/`MRP`로 그대로 유지한다.
[APC RPM 상한](https://www.apcprop.com/technical-information/rpm-limits/)

APC 자신은 SF를 멀티로터용으로 권장하며, 단서가 "호버 위주의 더 가벼운 기체"다.
즉 SF가 틀린 계열이 아니라, 이 기체의 추력 목표가 12인치 SF의 설계 영역 밖이다.

## 결론

다음 기준으로 시작한다.

- 최대 이륙질량: **설계 상한 1.5 kg**. Jetson·카메라를 제외한 구성 기준.
- 전원: **4S LiPo**.
- 추진: **APC 12×4.5MR + 12×4.5MRP를 사용하는 독립 모터 2개의 동축 반전 구조**.
- 추력 방향: 2축 TVC, 기계적 동작 범위 ±15° 이상, 초기 제어 명령은 ±8°로 제한.
- 실시간 제어: **PX4가 지원되는 Pixhawk FMUv6X급 비행제어기** 또는 동급 H7 보드.
- 고수준 연산: Jetson Orin Nano. VIO·영상·ROS 2·실험 기록 담당.
- 첫 실물 목표: 프로펠러 없는 TVC 벤치. Jetson은 초기에는 기체 밖에서 전원 어댑터로 사용.
- 첫 비행 목표: 센서 융합이나 MPC가 아닌, 비행제어기 단독 자세 안정화와 안전 종료 검증.

이 사양의 추력 판정은 [`research/propulsion_check.py`](../../research/propulsion_check.py)로 재현한다.
입력은 [`research/parameters/propulsion_candidate.json`](../../research/parameters/propulsion_candidate.json)이며,
값이 바뀌면 문서를 고치기 전에 도구를 다시 실행한다.

원본 약 0.4 kg 기체에 Jetson 개발키트와 대형 센서를 단순 추가하지 않는다. 탑재 후 질량과 관성이 달라지므로 추진계와 프레임을 새로 검증한다.
원본의 84 mm급 3MF를 균일 확대해서 사용하지도 않는다. 새 부품 치수와 질량을 기준으로 하중 골격, TVC 짐벌, 트레이와 분할 외피를 파라메트릭 CAD로 재설계한다.
세부 기준은 [확대 사양용 기체 CAD 재설계 계획](CAD-재설계-계획.md)에 정리했다.

## 1. 추력 요구조건

설계 상한 질량을 다음과 같이 둔다.

\[
m_{\max}=1.5\ \mathrm{kg}
\]

무게는 다음과 같다.

\[
W_{\max}=m_{\max}g=1.5\times9.80665\approx14.7\ \mathrm{N}
\]

배터리 저전압에서 보호 지그로 측정한 동축 조립체의 최대 총추력 목표는 무게의 1.7배로 둔다.

\[
T_{\max}\cos 15^\circ \ge 1.7\,W_{\max}
\]

따라서 추력축 기준 목표는 다음과 같다.

\[
T_{\max}\ge\frac{1.7\times14.7}{\cos15^\circ}\approx25.9\ \mathrm{N}
\]

즉, **4S 배터리의 최저 운용 전압에서 동축 조립체 실측 총추력 25.9 N 이상**을 1차 목표로 둔다.
이는 약 2.64 kgf에 해당한다.

### 추력/무게 1.7은 감수한 값이다

v0의 목표는 2.0이었다. 확정된 추진계로는 1.5 kg에서 2.0을 만들 수 없어 1.7로 낮췄다.
이것은 계산이 아니라 **2026-09-20에 내린 설계 결정**이며, 다음 두 가지를 감수한다는 뜻이다.

- 호버 스로틀이 높아져 외란·상승·배터리 강하에 쓸 여유가 줄어든다.
- 모터 2개 구조라 하나가 고장나면 대체 수단이 없다. 여유 감소가 그대로 위험으로 남는다.

따라서 구속 시험 범위를 v0보다 보수적으로 잡고, 실측 추력이 나오기 전에는 자유비행 단계로 넘어가지 않는다.

### 제조사 데이터 기준 현재 여유

아래는 실측이 아니라 APC 공표 정지추력표와 가정값으로 계산한 서류상 값이다.
동축 손실 20%, 부하 RPM을 무부하의 80%로 가정했다. 두 값 모두 측정으로 교체해야 한다.

| 조건 | 부하 RPM | 프롭 상한 대비 | 동축 총추력 | 필요 추력 | T/W | 목표 만족 질량 상한 |
|---|---:|---:|---:|---:|---:|---:|
| 공칭 전압 14.8 V | 7,696 | 88% | 25.5 N | 25.9 N | 1.73 | 1.48 kg |
| 최저 운용 전압 14.0 V | 7,280 | 83% | 22.8 N | 25.9 N | 1.55 | 1.32 kg |

**현재 구성은 문서 자신의 기준을 만족하지 않는다.** 공칭 전압에서 0.4 N, 최저 운용 전압에서 3.1 N 부족하다.
§1의 판정 기준이 최저 운용 전압이므로, 서류상으로는 미달 상태로 시작한다는 뜻이다.
1.5 kg를 유지하기로 했으므로 이 미달을 기록으로 남기고, 다음 중 하나로 해소한다.

- 실제 완성 질량이 1.3 kg 근처로 내려오면 자연히 해소된다. 질량 예산을 §9에서 관리한다.
- 동축 손실 실측값이 가정보다 작으면 여유가 늘어난다. 아래 민감도를 참고한다.
- 둘 다 아니면 추진계를 다시 고른다. 게인으로 보상하지 않는다.

동축 손실 가정에 따른 변화는 다음과 같다. 최저 운용 전압 기준이다.

| 가정 손실 | 동축 총추력 | T/W | 목표 만족 질량 상한 |
|---:|---:|---:|---:|
| 10% | 25.7 N | 1.74 | 1.49 kg |
| 15% | 24.2 N | 1.65 | 1.40 kg |
| 20% | 22.8 N | 1.55 | 1.32 kg |
| 25% | 21.4 N | 1.45 | 1.24 kg |

20%를 기본 가정으로 쓰는 근거는 운동량 이론이다. 상·하 로터가 하나의 유관을 완전히 공유하면
같은 추력에 유도동력이 \(\sqrt{2}\)배 필요하고, 등출력 기준 추력은 \(2^{-1/3}\approx0.794\)배가 된다.
즉 **20.6%가 이상적 최악값**이다. 실제 동축은 후류가 \(A/2\)로 수축해 하단 로터가 부분적으로만 잠기므로
손실이 이보다 작다. 따라서 20%는 보수적 설계값이며, 실측으로 교체할 대상이지 확정값이 아니다.

측정할 때는 **무엇을 고정했는지** 함께 기록한다. 등RPM, 등출력, 등스로틀 비교가 각각 다른 손실값을 준다.

### 트림에서 두 로터의 추력은 반반이 아니다

요가 돌지 않으려면 두 로터의 **토크**가 같아야 한다. 하단 로터는 열화된 유입 조건에서 돌기 때문에
같은 토크에서 내는 추력이 상단보다 적다. 따라서 트림 상태의 추력 분담은 대략 55:45–60:40으로 갈린다.

- "모터당 추력 × 2"로 총추력을 확정하지 않는다.
- 요 제어는 일부러 토크를 불균형하게 만드는 것이므로, 추력 분담과 총추력이 요 명령에 커플링된다.
- `my_airframe.json`의 `yaw_torque_per_differential_thrust`는 단독 모터 데이터로 채울 수 없다.
  동축으로 조립한 상태에서 반작용 토크를 직접 측정해야 한다.

## 2. 모터와 프로펠러 사양

### 확정 구성

| 항목 | 기준 사양 v1 |
|---|---|
| 모터 | D4215-21 650KV × 2, 각 모터를 독립 제어 |
| 배터리 | 4S |
| 프로펠러 | APC 12×4.5MR(정회전) + 12×4.5MRP(역회전) |
| 프롭 RPM 상한 | 8,750 (Multi-Rotor 계열, 105,000 ÷ 12인치) |
| 예상 부하 RPM | 7,280–7,700. 무부하의 80% 가정이며 실측 대상 |
| 단독 추력 | 모터당 14.3–16.0 N. APC 공표 정지추력표 기준 |
| 연속 운전 | 목표 호버 추력에서 과열 없이 반복 운전 가능해야 함 |
| 데이터 | 전압, 프로펠러, 추력, 전류, 입력, RPM, 온도 조건이 있는 시험표 필요 |

**이 조합에서 상한은 프롭이 아니라 모터·배터리 쪽이다.** 650KV × 4S는 부하 상태에서 약 7,700 RPM이
한계라, MR 프롭의 8,750 RPM 상한에는 도달하지 못한다. 프롭을 더 큰 피치로 바꿔도 모터가 못 돌린다.
추력을 더 원하면 프롭이 아니라 전압 또는 모터를 바꿔야 하며, 그때는 §11의 개정 절차를 따른다.

KV·모터 크기·프로펠러 직경 중 하나만으로 선택하지 않는다. 같은 KV라도 권선, 자석, 냉각, 프로펠러 피치에 따라 전류와 추력이 달라진다.
제조사 표가 단일 모터의 신품 배터리 조건만 제공한다면 최종 판정 자료가 아니다.
위 추력값은 APC의 정지추력 시뮬레이션 데이터이며, 모터·ESC 손실과 동축 간섭을 포함하지 않는다.

확인할 것:

- 두 모터의 회전 방향은 ESC에서 반대로 설정하고 MR/MRP 프로펠러를 정확히 대응시킨다.
- 프롭 허브 구멍과 모터 축 지름이 맞는지 확인한다. APC 단품 팩에는 어댑터 링이 들어 있지 않다.
- 12인치는 v0가 가정한 8–9인치보다 크다. 짐벌 회전 시 소요 공간과 프레임 간섭을 §5에서 다시 잡는다.
- 데이터가 없거나 프로펠러 조건이 다르면 **상태 불명**으로 두고 회전 시험 전에는 비행 후보로 확정하지 않는다.

프롭은 동일 제조사·형상·피치의 짝을 사용하고, 균열·변형·허브 손상이 있는 것은 폐기한다.
동축 간격은 고정값을 최적이라고 가정하지 말고 약 \(0.15D\)–\(0.35D\) 범위에서 조절 가능한 시험 구조로 만든다.
12인치(305 mm) 기준으로 **46–107 mm** 범위다. 간격이 좁으면 후류가 수축하기 전에 하단 로터가
더 많이 잠겨 손실이 커진다. 이 범위를 실제로 바꿔 가며 측정하는 것이 §1 손실 가정을 교체하는 방법이다.

## 3. ESC 사양

ESC는 4-in-1보다 냉각과 교체가 쉬운 **독립 ESC 2개**를 우선한다.

| 항목 | 기준 사양 v1 |
|---|---|
| 입력 전압 | 4S 정식 지원, 완충 전압 16.8 V 포함 |
| 연속전류 | 선택한 모터·프롭의 실측 최대전류의 1.25배 이상 |
| 단기 피크 | 실측 최대전류의 1.5배 이상 또는 제조사 허용 범위 확인 |
| 시작 후보 | **50–60 A급 독립 ESC 2개**. 예상 최대전류 약 22 A/모터 대비 2배 이상 여유 |
| 명령 | DShot300 이상, 가능하면 DShot600/BDShot |
| 텔레메트리 | eRPM 필수 권장, 전압·전류·온도 텔레메트리 권장 |
| 펌웨어 | PX4에서 사용할 프로토콜과 텔레메트리가 검증된 버전 |
| 냉각 | 동축 기류와 프레임 내부 온도를 고려해 실제 장착 상태에서 검증 |

eRPM 텔레메트리는 이 프로젝트에서 선택이 아니라 필요에 가깝다. §1의 부하 RPM 가정과 §2의 프롭 상한
준수 여부를 확인할 유일한 상시 수단이고, 동축 손실 측정에서도 "무엇을 고정했는지"를 기록하는 근거가 된다.

PX4의 DShot은 체크섬, ESC 보정 불필요, 텔레메트리 등의 장점이 있고, 지원되는 H7 계열 출력에서는 BDShot eRPM을 사용할 수 있다.
[PX4 DShot 공식 문서](https://docs.px4.io/main/en/peripherals/dshot)

정격 숫자만 믿지 않고, 보호 지그에서 전류·전압 강하·ESC 온도를 함께 기록한다.
ESC 정격을 키우는 것으로 커넥터·배선·전원분배 용량 문제가 해결되지는 않는다.

## 4. 배터리와 전원 계통

### 추진 배터리 시작점

| 항목 | 기준 사양 v1 |

| 전압 | 4S LiPo |
| 용량 후보 | 2,200–3,000 mAh. 질량 예산이 상한을 정한다 |

| 최저 운용 전압 | 셀당 3.5 V 가정. 팩 데이터시트와 실측 강하로 교체 |
| 모니터링 | 전체 전압, 전류, 사용량, 가능하면 셀 전압 |
| 주 전력 경로 | 배터리 → 전원분배/전류센서 → ESC 2개 |

**용량을 체공시간만 보고 고르지 않는다.** 1.5 kg 상한에서 배터리는 250–350 g을 차지하고,
§1에서 확인했듯 추력 여유가 이미 부족하다. 용량을 키우면 그만큼 질량 상한 여유가 줄어
T/W가 더 나빠진다. 용량 선택은 §9의 질량 예산과 함께 결정한다.

최저 운용 전압 3.5 V/셀은 가정이다. 이 값이 §1 추력 판정의 기준 조건이므로,
팩 데이터시트의 방전 하한과 호버 전류에서의 실제 강하를 측정해 교체한다.

예상 체공시간은 실측 평균전류를 얻은 뒤 다음으로 계산한다.

\[
t_{\mathrm{usable}}[\mathrm{min}]
=\frac{60\times0.8\times C[\mathrm{Ah}]}{I_{\mathrm{avg}}[\mathrm{A}]}
\]

0.8은 초기의 사용 가능 용량 가정이며 배터리 제조사·운용 전압·상태에 맞춰 조정한다.

### 전원을 세 계통으로 분리

1. **모터 계통:** 4S를 ESC에 직접 공급.
2. **서보 계통:** 별도 HV BEC. 기준 7.4–8.4 V, 연속 15 A 이상, 순간 25–30 A급 후보.
3. **비행제어기·컴퓨터 계통:** 비행제어기용 검증된 이중 전원 모듈과 Jetson용 전용 DC-DC.

Jetson Orin Nano 개발키트의 기본 전력 모드는 현재 공식 가이드에서 보통 25 W로 설명되고, 개발키트는 19 V 어댑터와 DC 잭을 사용한다.
공식 캐리어 보드 사양의 DC 입력 능력은 19 V, 4.2 A로 제시된다.
[NVIDIA 전원 모드](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/howto.html),
[개발키트 캐리어 보드 사양](https://developer.nvidia.com/downloads/assets/embedded/secure/jetson/orin_nano/docs/jetson_orin_nano_devkit_carrier_board_specification_sp.pdf)

**4S로 바뀌면서 이 부분의 방향이 뒤집혔다.** v0의 6S는 25.2 V에서 19 V로 낮추는 강압이었지만,
4S는 완충 16.8 V, 공칭 14.8 V로 **19 V보다 낮다**. 즉 승압이 필요하다.
따라서 개발키트를 기체에 올리려면 **4S 전 구간(약 14.0–16.8 V)을 입력으로 받아 19 V·최소 4.2 A를
안정적으로 내는 승압형 또는 벅부스트 DC-DC**가 필요하며, 강압형 모듈은 후보가 되지 않는다.
승압 구간에서는 입력 전류가 출력 전류보다 커지므로 배선·전원분배 정격도 다시 계산한다.

카메라·SSD·USB 장치 부하와 순간 응답을 포함하여 벤치에서 먼저 검증한다.
초기 TVC 벤치와 첫 자세 안정화 시험에서는 Jetson을 기체 밖에 두고 제공 어댑터로 전원 공급한다.

§1의 추력 여유와 §9의 질량 예산을 함께 보면, **1.5 kg 상한에서 Jetson 개발키트를 탑재할 여지는 없다.**
탑재는 9단계 기준선을 확보하고 추진계를 재검토한 뒤에 다시 판단한다.

서보, Jetson, 비행제어기에 하나의 저가 BEC를 공유하지 않는다. 각 전원 계통은 공통 기준 전위와 노이즈 경로를 의도적으로 설계하고,
배선 정격·역극성·과전류·서지 보호는 선택한 부품 제조사의 회로 지침에 맞춘다.

## 5. TVC 짐벌과 서보

원본 MG90S급은 새 1.5 kg 상한 기체의 최종 구동기로 확정하지 않는다. 다음을 시작 사양으로 둔다.

| 항목 | 기준 사양 v1 |
|---|---|
| 축 | 직교 2축, 실제 추력축을 회전 |
| 서보 | HV 디지털 금속기어 또는 BLDC 서보 2개 |
| 정격 토크 후보 | 정격 전압에서 25 kgf·cm 이상/축 |
| 속도 후보 | 무부하 사양 0.10 s/60° 이하. 실제 부하 응답은 별도 계측 |
| 입력 갱신 | 200 Hz 이상 지원 권장. 제어 주기와 실제 내부 갱신을 구분 |
| 출력각 | 기계 동작 ±15° 이상, 하드 스톱은 약 ±20°, 초기 명령 제한 ±8° |
| 감속 | 2:1–3:1 범위 후보. 토크·속도·유격의 교환관계를 실측 |
| 위치 측정 | 짐벌 출력축 엔코더 우선. 최소 12 bit, 반복 정밀도 0.2° 목표 |
| 유격 목표 | 출력축 왕복 히스테리시스 0.5° 이하를 목표로 측정 |

25 kgf·cm는 최종 설계 계산값이 아니라 첫 후보를 거르는 기준이다.
추력축이 회전 중심을 지나면 정적 추력 자체가 서보를 크게 비트는 구조를 피할 수 있지만,
모터·프롭의 자이로 효과, 케이블 힘, 질량 불균형, 축 오차, 진동 하중은 남는다.
최종 토크는 실제 조립체의 스텝 응답과 온도로 결정한다.

### 12인치로 커지면서 달라지는 것

v0는 8–9인치를 가정했다. 직경이 12인치(305 mm)로 커지면서 세 가지가 바뀐다.

- **소요 공간.** 짐벌이 ±15° 회전할 때 프롭 원판이 쓸고 지나가는 부피가 커진다.
  프레임·랜딩기어·배선이 이 부피 밖에 있어야 하고, 상·하 로터 간격 46–107 mm도 이 안에서 확보해야 한다.
  CAD-0에서 가장 먼저 확인할 간섭 조건이다.
- **로터 관성.** 같은 계열에서 관성은 대략 직경의 4제곱에 비례하므로, 8.5인치 대비 약 4배다.
- **자이로 토크는 생각보다 작다.** 반전 동축은 두 로터의 각운동량이 대부분 상쇄되므로
  짐벌 베어링이 받는 알짜 자이로 토크는 작다. 다만 요 제어로 차동을 주는 순간 상쇄가 깨져 잔여분이 남는다.
  이 잔여분은 요 명령 크기에 비례하므로, 서보 토크가 아니라 **축간 커플링** 문제로 다룬다.

따라서 서보 토크의 지배 요인은 자이로 효과가 아니라 기울어지는 조립체의 질량·관성, 케이블 강성,
추력축과 회전 중심의 편심이다. 편심 5 mm에서 25 N이면 약 0.13 N·m(1.3 kgf·cm)이므로,
25 kgf·cm 기준은 여유가 크다. 이 여유는 유격·분해능·응답속도를 확보하는 데 쓰고,
토크 숫자만 보고 더 큰 서보를 고르지 않는다. 서보가 무거워지면 §1의 추력 여유가 다시 줄어든다.

짐벌은 다음을 조절할 수 있게 설계한다.

- 두 로터 축 정렬.
- 상·하 로터 간격.
- 질량중심에서 TVC 유효 작용점까지 거리.
- 엔코더 영점과 서보 링크 길이.
- 케이블이 짐벌 토크에 미치는 영향.

출력 외피가 주요 추력 하중을 전달하도록 만들지 않는다. 모터 마운트, 짐벌 베어링 블록과 카본 골격을 주 하중 경로로 두고,
로켓 형상의 출력 쉘은 보호·공력·정비 패널 역할로 분리한다. 원본 짐벌과 프레임은 새 모터와 질량에 비례 확대하지 않고 새로 설계한다.

## 6. 비행제어기와 Jetson의 역할

### 실시간 비행제어기

PX4 기준선에는 **Pixhawk 6X/FMUv6X급**을 권장한다. FMUv6X는 STM32H753, 3개 IMU, 2개 기압계, 8개 FMU PWM, 2개 CAN을 제공하며 PX4의 표준 지원 대상이다.
[PX4 Pixhawk 계열 비교](https://docs.px4.io/main/en/flight_controller/pixhawk_series)

필요 기능:

- H7급 MCU와 충분한 로깅 성능.
- 모터 2개용 DShot/BDShot 출력.
- TVC 서보 2축 출력 또는 별도 스마트 액추에이터 버스.
- 전원 이중화 또는 독립적인 안정 전원.
- Jetson과 연결할 TELEM/UART, CAN 또는 Ethernet.
- 안전 스위치, RC 수동 개입, 독립적인 KILL 경로.

표준 쿼드로터 airframe 설정을 그대로 사용하지 않는다. 이 기체는 모터 2개와 TVC 2축의 맞춤 제어 할당과 airframe 정의가 필요하다.

### Jetson Orin Nano

Jetson이 담당할 것:

- 카메라 드라이버와 하드웨어 타임스탬프 확인.
- VIO, AprilTag, 장애물/착륙 지점 인식.
- ROS 2 노드, rosbag/영상 로그.
- 저속 위치·경로·착륙 목표 생성.

Jetson이 처음부터 담당하지 않을 것:

- 모터 정지에 필요한 유일한 KILL 경로.
- 200–500 Hz 자세 내부 루프.
- 통신이 끊기면 유지할 수 없는 유일한 안정화 제어기.

PX4는 companion computer의 ROS 2 통합을 지원하지만, Offboard 링크 손실 시 별도 failsafe 동작을 설정해야 한다.
[PX4 ROS 2](https://docs.px4.io/main/en/ros2/), [Offboard 손실 안전설정](https://docs.px4.io/main/en/config/safety)

## 8. 계측·안전 장비

준비할 장비:

- 0.1 g 분해능 이상의 전자저울과 캘리퍼. 질량 예산이 빡빡하므로 저울은 초기부터 상시 사용한다.
- 로드셀. 설계 목표가 25.9 N이므로 50 N급을 기본 후보로 두고, 지그 하중과 과도 응답을 고려해 여유를 확인한다.
  용량이 크기만 하면 목표 범위의 분해능이 나빠진다.
- 로드셀 증폭기/DAQ, 별도 전압·전류 측정, 광학 또는 ESC RPM 측정.
  RPM 측정은 §1의 부하 RPM 가정과 §2의 프롭 상한 준수를 확인하는 필수 항목이다.
- 4S·60 A 이상 후보의 전원분배/전류센서. 풀스로틀 합산 약 44 A가 기준이며,
  최종 정격은 실제 최대전류와 배선으로 확정한다.
- 출력축 엔코더 2개 또는 각도 추적용 고속 카메라와 명확한 마커.
- 오실로스코프 또는 로직 분석기, 멀티미터, 온도 측정 수단.
- 튼튼하게 고정되는 추력 지그, 프로펠러 비산을 고려한 보호 구조, 시험자와 충분한 이격.
- 손을 떼어도 정지 상태로 유지되는 원격 비상정지와 독립적인 모터 신호 차단.
- 배터리 제조사의 충전·보관·손상 대응 지침을 따를 수 있는 비가연성 시험 공간.

로드셀 용량이 크기만 하면 좋은 것은 아니다. 목표 추력 범위에서 충분한 분해능과 샘플링 속도가 있어야 한다.
회전 시험 전에는 지그 고정, 구조 하중, 프로펠러 파손 경로, 원격 차단을 별도로 검토한다.

## 9. 지금 바로 해야 할 다음 단계

### A-0. 질량 예산부터 세운다

v1에서 가장 먼저 관리할 것은 부품 선정이 아니라 **질량**이다. §1에서 추력 여유가 이미 부족하고,
질량 1 g이 늘 때마다 T/W가 직접 나빠진다. 아래는 계획용 개략값이며, 확정값이 아니라 **채워야 할 표**다.

| 항목 | 개략 질량 | 상태 |
|---|---:|---|
| 모터 2개 (4215급) | 320 g | 실측 필요 |
| 프로펠러 2개 (APC 12인치) | 40 g | 실측 필요 |
| ESC 2개 (50–60 A) | 110 g | 실측 필요 |
| 배터리 (4S 2,200–3,000 mAh) | 250–350 g | 실측 필요 |
| TVC 서보 2개 | 120 g | 미선정 |
| 짐벌·카본 골격·출력 부품 | 300 g | CAD-0 이후 |
| 비행제어기·배선·커넥터·센서 | 120 g | 미선정 |
| **합계** | **약 1,260–1,360 g** | |

합계가 1.5 kg 상한에 140–240 g밖에 남기지 않는다. 이 여유는 배선 정리, 체결 부품, 보강, 보호 구조에
금방 소모된다. 따라서 다음을 규칙으로 둔다.

- 부품을 받는 즉시 저울에 올리고 표의 값을 실측으로 교체한다.
- 개략값 대비 초과분이 생기면 그 자리에서 기록하고, 누적 초과가 100 g을 넘으면 §11 절차로 넘어간다.
- Jetson·카메라·SSD·DC-DC는 이 표에 넣지 않는다. 1.5 kg 상한에서는 탑재 대상이 아니다.

실측값이 모이면 [`research/parameters/propulsion_candidate.json`](../../research/parameters/propulsion_candidate.json)의
`target_mass`를 갱신하고 `propulsion_check.py`를 다시 실행해 §1 표를 교체한다.

### A. 장비 적합성 표 만들기

보유 장비를 다음 형식으로 보내거나 기록한다.

```text
Jetson: 정확한 모델 / 개발키트 또는 모듈+캐리어 / 저장장치 / 실측 질량
카메라: 모델 / 인터페이스 / 최대 FPS / 글로벌·롤링 셔터 / IMU 포함 여부 / 실측 질량
비행제어기: 모델 / PX4 버전 / 사용 가능한 출력과 포트
모터: 모델 2개 / KV / 정격 4S 여부 / 실측 질량 / 제조사 추력표 링크
프로펠러: 직경×피치 / CW·CCW / 재질 / 제조사

```

모델명과 실제 질량이 우선이다. 맞지 않는 장비는 바로 버리지 않고 무회전 벤치·시뮬레이션·보조 계측에 재사용할 수 있는지 구분한다.

### B. Jetson·카메라를 기체 밖에서 먼저 검증

1. 제공 전원으로 Jetson을 부팅한다.
2. 전력 모드, JetPack 버전, 저장장치 여유를 기록한다.
3. 카메라 스트림과 IMU 원시 데이터를 동시에 기록한다.
4. 프레임 FPS, 누락, 타임스탬프 단조 증가, CPU/GPU 부하와 온도를 기록한다.
5. 손으로 움직이는 카메라 리그에서 VIO 공개 예제 또는 기록 재생을 확인한다.

이 단계에는 모터와 프로펠러가 필요 없다.

### B와 병행 — 부품 실측과 CAD-0

1. 모터, 프로펠러, ESC, 서보, 배터리, Jetson, 카메라, 비행제어기의 정확한 모델과 질량을 기록한다.
2. 캘리퍼로 외형, 장착홀, 축, 커넥터와 케이블 출구를 측정한다.
3. 프린터 빌드 볼륨, 노즐과 사용할 재료를 기록한다.
4. 부품 엔벌로프와 카본 골격부터 배치하고, 완성 외피는 CAD-3 이후 출력한다.

상세 입력표와 제작 게이트는 [CAD 재설계 계획](CAD-재설계-계획.md)을 따른다.

### C. 프로펠러 없는 TVC 벤치 제작

1. 모터 대신 같은 질량의 더미 또는 모터만 장착하고 프로펠러는 제거한다.
2. 짐벌 출력축에 각도 엔코더 또는 추적 마커를 설치한다.
3. 비행제어기, 서보 전원, KILL, 명령 타임아웃을 연결한다.
4. ±1°, ±3°, ±5°, ±8°의 계단 명령을 양방향으로 반복한다.
5. 명령각·실제각·전압·시간·포화 여부를 하나의 로그에 남긴다.
6. 축 부호, 영점, 속도, 지연, 오버슈트, 히스테리시스를 계산한다.

이 벤치가 통과하면 `my_airframe.json`의 서보 관련 값을 `measured` 또는 근거가 분명한 `assumed`로 채운다.

## 10. 전체 개발 과정

| 단계 | 작업 | 다음 단계로 넘어가는 조건 |
|---|---|---|
| 0. 보유품 판정 | 정확한 모델·질량·데이터시트와 기준 사양 비교 | 목표 질량표와 전원 구조 초안 완성 |
| 0.5. CAD 기준선 | 부품 실측, 골격·짐벌·트레이·분할 외피 재설계 | 간섭 없는 전체 조립과 질량중심 조절 범위 확인 |
| 1. Jetson/카메라 독립 검증 | 영상·IMU·타임스탬프·온도·저장 성능 확인 | 30분 이상 로그에서 누락과 시간 문제 설명 가능 |
| 2. 무회전 TVC 벤치 | 짐벌 축·영점·지연·속도·유격·KILL 검증 | 반복 가능한 실제각 로그 확보 |
| 3. 추진계 시험대 | 단일 로터와 동축의 추력·전류·RPM·온도·토크 측정 | 저전압에서 25.9 N 목표 평가, 동축 손실 실측으로 §1 가정 교체 |
| 4. 파라미터 확정 | 질량·CoM·관성·레버암·구동기·추력 계수 기록 | 별도 검증 데이터에서 모델 오차 수치화 |
| 5. Gazebo/SIL | 맞춤 TVC 플러그인·센서 지연·고장·제약 구현 | 기준 LQI가 목표 초기조건에서 반복 안정화 |
| 6. 제어 연구 | LQI → 지연 확장 LQI → 제약 MPC/INDI 비교 | 같은 입력·외란 조건에서 지표와 실패 사례 확보 |
| 7. HIL | 실제 FC·ESC 신호·서보·통신·Jetson 연결 | 최악 실행시간, 포화, 링크 손실, 센서 오류 안전 동작 |
| 8. 제한 실기 | 보호된 구속 시험 후 작은 자세·추력 범위 | 수동 KILL과 자동 timeout, 모델 예측과 로그 확인 |
| 9. 초기 자유비행 | Jetson 없이 FC 단독 자세·고도 안정화 | 안전구역에서 반복 이륙·호버·착륙, 이상 종료 가능 |
| 10. VIO 통합 | Jetson 위치 추정은 보조 입력으로 추가 | 외부 기준 대비 지연·오차·드롭아웃 평가 |
| 11. 확장 연구 | GPS 없는 위치 유지, 정밀 착륙, MPC/강인제어 | 기준선과 동일 조건의 정량 비교 및 재현 가능한 데이터 |

구속 시험의 줄과 지그는 기체에 힘을 추가하므로 자유비행 모델과 같은 데이터로 취급하지 않는다.
Jetson과 카메라는 1단계에서 먼저 연구할 수 있지만, 기체 탑재는 9단계 기준선을 확보한 뒤 진행한다.

## 11. 바꾸어야 하는 조건

다음 중 하나가 발생하면 기준 사양 v1을 수정한다.

- 실제 완성 질량이 1.5 kg를 넘음. 누적 초과가 100 g을 넘는 시점에 미리 검토한다.
- 동축 저전압 실측 총추력이 25.9 N 미만. 서류상 이미 미달이므로, 실측으로 확인되면
  질량을 줄이거나 추진계를 바꾼다. 목표 T/W를 1.7 아래로 더 낮추는 것은 선택지로 두지 않는다.
- 실측 부하 RPM이 프로펠러 계열 상한을 넘음. 이 경우 즉시 회전 시험을 중단한다.
- 호버 추력에서 모터·ESC·배터리·배선 온도 또는 전압 강하가 허용되지 않음.
- 짐벌 출력축 지연·유격이 목표 제어 대역폭을 만족하지 못함.
- Jetson DC-DC가 카메라·SSD 부하에서 재부팅하거나 비행제어기 센서에 간섭을 만듦.
- 카메라 시간 동기화 또는 드라이버가 선택한 JetPack/ROS 2 환경에서 재현되지 않음.
- 맞춤 제어 할당과 failsafe를 현재 비행제어기에서 안전하게 구현할 수 없음.

수정은 실패가 아니라 이 과정의 정상적인 설계 반복이다. 단, 실측에서 부족한 추진계나 전원 문제를 제어 게인으로 보상하려고 하지는 않는다.
