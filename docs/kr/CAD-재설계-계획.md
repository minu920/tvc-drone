# 6단계 — 확대 사양용 기체 CAD 재설계 계획

작성: 2026-09-16. 이 문서는 1.3–1.8 kg, 6S, 8–9인치 동축 반전 추진계와 Jetson Orin Nano 탑재를 가정한 **설계 기준선**이다.
치수가 확인되지 않은 값은 제작 치수가 아니라 초기 후보이며, 실제 부품 실측 후 확정한다.

## 결론

로켓 형상은 3D 프린터로 제작할 수 있다. 다만 가장 먼저 완성 외피부터 출력하지 않는다.

1. 실제 부품의 치수와 질량을 측정한다.
2. 하중을 받는 카본 골격과 TVC 짐벌을 먼저 설계한다.
3. 간섭·질량중심·배선·냉각을 확인하는 부분 시제품을 출력한다.
4. 마지막에 골격을 감싸는 분할 외피를 설계하고 출력한다.

외피를 먼저 만들면 모터, 서보, 배터리 또는 Jetson 크기가 바뀔 때 거의 전부 다시 출력해야 한다.
또한 원본을 균일 비율로 확대하지 않는다. 길이를 (s)배 키우면 표면적은 대략 (s^2), 같은 비율의 속이 찬 형상 질량은 (s^3)에 비례하지만,
적층 방향 접합 강도와 기어 유격이 같은 비율로 개선되는 것은 아니다.

## 원본 CAD 감사 결과

원본 저장소에는 기체용 STEP, Fusion 또는 FreeCAD 원본이 없고 출력용 3MF만 있다.
따라서 3MF는 외형 참고와 치수 비교에 사용하고, 새 기체는 편집 가능한 파라메트릭 CAD로 다시 만든다.

| 원본 파일 | 확인한 메쉬 범위 | 새 설계 판단 |
|---|---:|---|
| `airframes.3mf` | 외경 약 84 mm, 분할 길이 108/121/231 mm, 노즈 높이 125.5 mm | Jetson과 새 전원·배선 공간을 반영해 재설계 |
| `frames.3mf` | 약 61–74 mm 폭 | 새 골격과 보드 트레이로 교체 |
| `outer-frames.3mf` | 외경 약 83 mm | 새 외경에 맞춰 교체 |
| `tvc.3mf`, `gears.3mf` | 약 70–81 mm급 짐벌, 별도 소형 기어 | 모터·베어링·서보·엔코더 기준으로 완전 재설계 |
| `landing-gear.3mf` | 약 12–22 mm급 연결 부품 | 새 질량과 착지 하중에 맞춰 재설계 |

## 구조 원칙

### 1. 출력 외피와 하중 골격을 분리

- **주 하중 경로:** 모터 마운트 → 짐벌 베어링 블록 → 카본 튜브 골격 → 배터리·항전장비 트레이.
- **출력 외피의 역할:** 공기 흐름 정리, 배선·전자장비 보호, 외형, 탈착식 점검 패널.
- **구조 체결:** 모터와 짐벌에는 관통 볼트, 너트, 금속 스페이서와 베어링을 사용한다. 열삽입 인서트는 반복 탈착 패널에는 좋지만 주요 추력 하중의 유일한 체결점으로 쓰지 않는다.
- **초기 후보:** 원본 3 mm 솔리드 로드 대신 4개의 8 mm 외경 카본 튜브를 검토한다. 벽 두께와 실제 허용 하중은 구매품 데이터와 정적 시험으로 확정한다.

이 구조에서는 외피가 깨져도 추력 하중 경로가 즉시 분리되지 않도록 설계할 수 있고, 외피만 다시 출력하기도 쉽다.

### 2. 완성 외형은 분할 쉘로 제작

- 좌우 또는 3분할 클램셸 구조로 만들어 전자장비에 접근할 수 있게 한다.
- 출력기 높이에 맞춰 노즈, 항전장비 구간, 배터리 구간, 짐벌 구간으로 나눈다.
- 섹션 접합부는 정렬 핀과 관통 볼트로 고정하고, 외피 단면만으로 굽힘을 전달하지 않는다.
- Jetson 구간에는 흡·배기 통로와 팬 교체 공간을 두고, 카메라 구간에는 렌즈 시야를 침범하지 않는 창과 진동 절연 마운트를 둔다.
- ESC와 전원부의 냉각 경로를 Jetson 배기와 무조건 공유하지 않는다.

### 3. 질량중심을 조절할 수 있게 제작

배터리 트레이와 Jetson 트레이를 기체 축 방향 레일에 장착한다. 완성 후 질량중심을 맞추기 위해 납을 추가하는 대신 무거운 부품의 위치를 조절한다.
CAD에서 계산한 질량중심은 다음 관계를 실물 측정으로 다시 확인한다.

\[
\mathbf r_{CG}=\frac{\sum_i m_i\mathbf r_i}{\sum_i m_i}
\]

## 확대 사양용 초기 형상 범위

아래 값은 `assumed` 상태의 레이아웃 후보다. 부품 치수가 들어오기 전에는 출력 파일로 확정하지 않는다.

| 항목 | CAD v0 후보 | 확정 방법 |
|---|---:|---|
| 외피 외경 | 115–125 mm, 초기값 120 mm | Jetson 캐리어, 커넥터, 배선 굽힘 반경과 냉각 간극으로 결정 |
| 전체 길이 | 750–850 mm | 질량중심, 짐벌 레버암, 배터리와 항전장비 적층 결과로 결정 |
| 주 골격 | 4 × 8 mm OD 카본 튜브 후보 | 튜브 사양, 좌굴·굽힘 계산과 정적 시험 |
| 외피 벽 | 1.6–2.0 mm 후보 | 재료, 노즐, 출력 방향과 부분 시편 시험 |
| 프롭 직경 | 203.2 또는 228.6 mm | 실제 8/9인치 프로펠러 모델로 간섭 검사 |
| 동축 로터 간격 | (0.15D\)–\(0.35D), 약 30–80 mm 조절식 | 단일·동축 추력 시험에서 확정 |
| TVC 동작 | 기계 ±15° 이상, 하드 스톱 약 ±20° | 실제 모터·배선·프롭 간섭 검사 |
| 초기 소프트웨어 제한 | ±8° | 무회전 구동 시험과 제어 검증 뒤 확장 |

120 mm 외경은 Jetson 개발키트가 들어갈 가능성을 보기 위한 첫 후보일 뿐이다. 사용 중인 Jetson이 개발키트인지 모듈과 소형 캐리어 조합인지에 따라 외경을 줄일 수 있다.
외경과 길이를 동시에 키우면 횡관성이 빠르게 증가하므로, 부품을 확인하지 않고 넉넉하게만 만드는 것은 피한다.

## TVC 짐벌 재설계 기준

- 모터 두 개와 프로펠러 두 개의 축을 하나의 2축 짐벌이 함께 기울이는 구조를 기준으로 한다.
- 두 축에는 베어링을 사용하고, 서보 출력축 자체가 모터 조립체의 모든 굽힘 하중을 받지 않게 한다.
- 추력축이 가능한 한 짐벌 회전 중심을 지나도록 모터 위치를 조절한다.
- 서보 또는 BLDC 액추에이터는 링크·벨트·저유격 감속을 통해 구동하고, 출력축 각도 엔코더를 별도로 둔다.
- 케이블은 중립각에서 당김이 없고 ±20°에서 최소 굽힘 반경을 지키도록 서비스 루프를 만든다.
- 모터 마운트와 베어링 블록은 출력 방향에 민감한 단일 플라스틱 부품 하나에 의존하지 않는다. 초기 벤치에서는 PA-CF/PA-GF 출력물을 평가할 수 있지만, 최종 비행체의 핵심 축과 체결부에는 금속 부품을 우선 검토한다.

짐벌의 필요한 서보 토크는 카탈로그의 정지 토크만으로 확정하지 않는다. 실제 조립체의 관성 (I_g), 목표 각가속도 (ddot\theta), 불평형 모멘트와 마찰을 포함해 다음 형태로 예산을 잡는다.

\[
\tau_{req} \ge I_g\ddot\theta + \tau_{unbalance}+\tau_{cable}+\tau_{friction}
\]

그 뒤 감속비, 효율, 순간 하중 여유를 포함해 액추에이터를 선택하고 무회전 벤치에서 응답을 측정한다.

## 사용할 CAD 방식과 납품물

최대한 오픈소스를 사용하기 위해 편집 원본은 **FreeCAD 파라메트릭 모델**을 기준으로 하고, 반복 생성이 필요한 형상은 Python 기반 스크립트로 관리한다.
최종적으로 다음을 만든다.

- 편집 가능한 FreeCAD 원본과 설계 파라미터 파일.
- 전체 조립 STEP.
- 부품별 STL과 프린터용 3MF.
- 모터·서보·베어링·카본 튜브·나사 BOM.
- 조립 순서, 체결 방식, 출력 방향과 재료 표.
- 전체 질량, 질량중심, 관성 텐서가 들어간 CAD 결과 기록.
- TVC ±20° 스윕, 프롭 디스크, 배선, 카메라 시야, 정비 공간의 간섭 검사 결과.

CAD에서 나온 질량과 관성은 `research/parameters/my_airframe.json`에 `cad` 상태로 옮기되, 실측값으로 표시하지 않는다.
기체 형상이 바뀌면 CAD 버전과 조립 구성을 출처에 함께 기록한다.

## CAD를 시작하기 전에 필요한 실측값

모델명만으로 얻는 도면과 실제 부품 치수가 다를 수 있으므로 캘리퍼와 저울로 다음을 기록한다.

```text
3D 프린터: 모델 / 빌드 볼륨 X×Y×Z / 노즐 / 가능한 재료
모터 2개: 모델 / 외경×높이 / 축·허브 / 장착홀 패턴 / 나사 / 전선 출구 / 각 질량
프로펠러: 직경×피치 / 허브 외경·두께·구멍 / CW·CCW / 질량
ESC 2개: 기판 또는 케이스 X×Y×Z / 장착홀 / 커넥터 포함 질량 / 냉각면
짐벌 액추에이터 2개: 모델 / 케이스 치수 / 출력축·스플라인 / 장착홀 / 혼 / 질량
베어링·축: 보유 모델과 치수, 없으면 미정
배터리: X×Y×Z / 케이블 출구 / 질량
Jetson: 개발키트 또는 모듈+캐리어 모델 / 방열판·팬 포함 X×Y×Z / 질량
비행제어기·전원모듈·DC-DC: 각 X×Y×Z / 장착홀 / 커넥터 방향 / 질량
카메라·렌즈: 본체와 렌즈 치수 / 장착홀 / 케이블 출구 / 질량 / 필요한 시야각
카본 튜브: 외경·내경·길이 또는 구매 예정 규격
```

치수 사진에는 자 또는 캘리퍼 눈금과 부품 방향을 같이 보이게 한다. 커넥터가 꽂힌 상태의 길이와 케이블 최소 굽힘 반경도 포함한다.

## 제작 게이트

| 게이트 | 제작물 | 통과 조건 |
|---|---|---|
| CAD-0 | 부품 엔벌로프와 질량표 | 모든 핵심 부품 치수·질량·커넥터 방향 기록 |
| CAD-1 | 골격·트레이 배치 | 목표 질량중심 조절 범위, 공구 접근과 배선 공간 확인 |
| CAD-2 | 무회전 짐벌 시제품 | ±20° 간섭 없음, 축 유격과 실제각 기록 가능 |
| CAD-3 | 부분 외피와 보드 더미 | 조립·분해·냉각·카메라 시야 확인 |
| CAD-4 | 전체 조립 CAD | 질량 예산, 질량중심, 관성, 프롭 디스크 간섭 검토 완료 |
| CAD-5 | 전체 출력·무회전 조립 | 체결 검사, 정적 하중 시험, KILL과 배선 검사 완료 |

회전 시험과 비행 시험은 CAD 완료만으로 허용되지 않는다. 적층 제조물은 재료 건조, 프린터 보정, 출력 방향, 공극과 체결 토크에 따라 강도가 크게 달라지므로 부분 시편과 실제 조립 정적 시험을 별도로 수행한다.
